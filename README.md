🎓 CampusConnect – College Event Management System

CampusConnect is a web-based College Event Management System designed to simplify the process of discovering, organizing, managing, and registering for college events. It provides a centralized platform where students can explore upcoming events, organizers can submit event proposals, and administrators can manage and approve events.

🚀 Features

👨‍🎓 Student Features

- Browse upcoming college events.
- Search and filter events by category and date.
- View detailed event information.
- Register for events online.
- View registration history.
- Cancel event registrations.
- Submit feedback for completed events.
- Receive registration notifications.

🧑‍💼 Organizer Features

- Submit new event proposals.
- Edit existing events.
- Manage event details.
- View registered participants.
- Track event registration counts.
- Upload event posters.

🛡️ Admin Features

- Approve or reject event proposals.
- Add, edit, and delete events.
- Manage registrations.
- View event statistics.
- Analyze participants by event category.
- Export participant information as CSV.

📅 Additional Features

- Interactive event calendar.
- Event countdown timer.
- Featured events section.
- Multiple event categories.
- Responsive user interface.
- LocalStorage-based data persistence.

⚙️ Installation and Setup

Follow these steps to run the project:

1. Clone the repository:
   
   git clone https://github.com/shaiksameer7141-svg/Campus-Connect.git

2. Navigate to the project folder:
   
   cd Campus-connect

3. Open the project folder in Visual Studio Code or another code editor.

4. Open "index.html" in your web browser.

5. Start exploring CampusConnect!

You can also use the Live Server extension in Visual Studio Code.

👥 User Roles

CampusConnect supports three demo user roles:

- Student: Explore events and register for them.
- Organizer: Create and manage event proposals.
- Administrator: Approve proposals and manage the platform.

Demo admin passcode: "admin123"

Note: This is a demonstration project. Authentication and role management are implemented on the client side and are not suitable for production use.
